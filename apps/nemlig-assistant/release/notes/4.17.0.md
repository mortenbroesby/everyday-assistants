# Nemlig Assistant 4.17.0 - Gallery

## In plain language

Ask to see your actual Nemlig basket visually to open product images where available. The basket stays unchanged. If ChatGPT cannot display the card, it still has every basket line in text and should say plainly that no card appeared.

## Changes

- Add a separate read-only visual basket action that fetches exact details for at most 12 current basket lines, three at a time, with an eight-second budget per detail. The regular basket read remains fast and image-free.
- Reuse the shared viewer for images, quantities, and line totals, and distinguish the actual Nemlig basket from the temporary local review.
- Keep all basket lines visible when details are missing or the basket is larger than the detail limit; reject mismatched product IDs and unsafe image origins.
- Guide ChatGPT to reopen the local review when asked to see chosen draft products, or use the visual basket action for actual provider-basket products, without claiming image URLs alone are visible cards.
- Add MCP, gateway, acceptance, and browser-smoke coverage with zero basket writes.
- Record the last completed service-fixture operation without exposing MCP payloads if protected rollout acceptance fails; preserve the primary failure if transport close also fails.
- Treat a successful recovery rebuild of the same source SHA as a distinct accepted Container image when its exact journal time and digest differ, while rejecting conflicting evidence and preserving the prior image history.

This release does not deploy itself. Hosted deployment and a fresh ChatGPT client check require separate approval.
