# Nemlig Assistant 4.16.0 - Trolley

## In plain language

Keep one temporary shopping basket in the current conversation and move freely between products to review, alternatives, and accepted choices. The compact green interface follows the approved shopping mockup.

## Changes

- Local baskets no longer expire after one hour. They are scoped to the authenticated conversation and discarded by Finish shopping, server restart, or bounded memory eviction; they are not saved lists.
- Add more products without restarting the review, or move accepted products back to Needs review. Voice and touch use the same state.
- Search tools return data without opening repeated widgets. Review widgets initialize the standard MCP Apps bridge and show actionable errors instead of waiting indefinitely.
- Sending to Nemlig still requires a fresh exact review and explicit approval. Local actions never change the real basket.
- Release checks reject stale viewer content and metadata; UI delivery also requires a verified ChatGPT app refresh and live local-review test.
