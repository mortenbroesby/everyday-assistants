# Nemlig Assistant 4.13.4 - Signal

## In plain language

Nemlig Assistant now records bounded, privacy-safe timing and response-size
signals around MCP startup requests. This makes authentication, admission, and
Container latency measurable without logging request contents, credentials,
tool arguments, or provider data.

## Changes

- Classifies common MCP startup methods in terminal gateway events.
- Records bounded authentication, Durable Object admission, and backend
  durations.
- Records trusted response sizes only when a bounded `Content-Length` exists.
- Preserves deterministic sampling for ordinary protocol successes and
  authentication noise.
