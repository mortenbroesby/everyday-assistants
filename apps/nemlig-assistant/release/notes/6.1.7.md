# Nemlig Assistant 6.1.7 - Stillwater

## In plain language

This release stops treating a sleeping Cloudflare Container as a failed
deployment after it has already answered the authenticated acceptance request.
It keeps the proof that matters: the exact deployed Worker revision, immutable
Container image and application version, strict MCP server version, and the
read-only service fixture.

## Changes

- Keep the immediate Container rollout strategy.
- Remove post-request instance-liveness polling from normal deployment and
  recovery acceptance.
- Restore an accepted Container image with the immutable historical version's
  logging configuration and the complete documented rollout request shape.

## Safety

The deployment still serializes only an unresolved non-atomic recovery,
performs no provider or basket mutation, and refuses an uncertain restore
instead of retrying it automatically.
