# Nemlig Assistant 6.2.1 - Juniper

## In plain language

New Draft-list cards now receive a fresh viewer identity whenever the UI changes,
so ChatGPT cannot combine current shopping data with an older cached interface.

## Changed

- Moved the live viewer resource to a new v13 URI.
- Kept every earlier viewer URI as an inert, read-only retirement page.
- Added service and production inventory checks for the current and retired
  viewer resources.
