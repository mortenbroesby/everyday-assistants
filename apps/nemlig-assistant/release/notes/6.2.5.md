# Nemlig Assistant 6.2.5 - Northstar

## In plain language

New ChatGPT connections use one permanent Draft list viewer identity instead of
another versioned card address. Earlier product-viewer cards remain safely
read-only, and resource reads now leave a small privacy-safe binding record for
diagnosis.

## Changed

- Registered `ui://nemlig/draft-list.html` as the permanent live MCP Apps
  viewer identity and retired the former unversioned and v1-v16 identities.
- Added a non-secret viewer build marker and SHA-256 identity for the exact
  self-contained HTML served by the current resource.
- Added one bounded authenticated resource-read diagnostic with only a
  request-local correlation ID, URI class, and current artifact digest.

## Safety

- The real Nemlig basket behavior, authorization, submission, and readback
  paths are unchanged.
- This release does not reconnect ChatGPT, alter OAuth, access the provider,
  or change any real basket.
