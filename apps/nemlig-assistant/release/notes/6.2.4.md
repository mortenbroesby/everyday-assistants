# Nemlig Assistant 6.2.4 - Nectar

## In plain language

The Draft list now starts with a consistent Nemlig Assistant workspace shell,
so a newly rendered card no longer looks like a separate, older product viewer.

## Changed

- Moved the live viewer resource to v16 and retained v15 as an inert retired
  page, so new cards do not pair this release's tool metadata with cached v15
  viewer content.
- Added one reusable Nemlig Assistant / Draft list shell around active product,
  outcome, empty, and unavailable views.
- Removed duplicate generic headings above empty, verified, and uncertain
  outcome surfaces while preserving their existing safe actions and text
  fallback.
- Updated the viewer resource title to **Nemlig Assistant**.
