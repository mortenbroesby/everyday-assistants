# Nemlig Assistant 5.2.2 - Page

## In plain language

Product searches without a requested count now use Nemlig's 20-item first page.

## Changes

- Always send Nemlig's `take` parameter, defaulting to 20 when the caller omits
  a result count, while preserving explicit requested counts.
- Replace the test that expected `take` to be omitted with a regression test
  for the 20-item default.

## Acceptance boundaries

The package checks, build, and tests are run against the release candidate.
Live ChatGPT search acceptance remains pending until this exact release is
deployed; no basket mutation is part of this change.
