# Nemlig Assistant 4.6.1-alpha.70

This maintenance release removes an unused principal-scope module and
consolidates repeated basket-write, production-acceptance deadline, and
Cloudflare admin-control execution paths. The runtime source is smaller while
retaining the existing public interfaces, authorization order, total deadlines,
bounded error responses, terminal events, and single-attempt basket mutations.

Focused characterization now covers both administrative controls and both
acceptance deadline contexts. Basket add, exact-line removal, absence checks,
readback verification, and clear-basket behavior remain unchanged. No
dependency, service, retry, quota, storage, or production configuration was
added or changed.
