# Nemlig Assistant 6.0.0 - Clarity

## In plain language

Shopping uses a temporary Draft list for deciding what to add and a separate Nemlig basket for what is already there. The assistant now presents six focused actions.

## Changes

- Keep product search, connection check, and the real Nemlig basket read.
- Keep the Draft list start, update, and exact Ready submission flow.
- Remove the profile, reconnect, favourites, section browsing, exact details, visual basket, and duplicate direct basket preparation and apply tools from the MCP catalog. This intentionally breaks clients that call those tools by name.
- Use Draft list, To decide, Ready, and Nemlig basket consistently in the viewer and agent guidance.
- Preserve add-only basket writes, exact preparation and authorization, single-use submission, and verified readback.

## Acceptance boundaries

Local checks and fixture-backed smoke tests cover the revised surface. Live ChatGPT catalog refresh and hosted behavior require deployment of this exact release and are not claimed here. No real Nemlig basket was changed during this work.
