# Nemlig Assistant 4.13.7 - Signal

## In plain language

ChatGPT can now associate a Nemlig OAuth connection with the authenticated
profile that owns it.

## Changes

- Added the read-only `get_profile` tool required for stable ChatGPT account
  identification.
- The profile identity is derived from the validated Auth0 principal and does
  not expose provider credentials or change basket behavior.

No provider configuration, basket mutation, checkout, payment, ordering,
delivery, or production deployment was performed by this change.
