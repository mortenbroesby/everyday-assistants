# Nemlig Assistant 4.14.2 - Rejoin

## In plain language

ChatGPT can reconnect to Nemlig Assistant using the MCP handshake it actually sends. Failed backend handshakes now appear as failures in Cloudflare's privacy-safe request logs.

## Changes

- Serve supported 2025-era streamable HTTP requests alongside the current MCP protocol, using the same authenticated tool definitions.
- Accept the SDK's supported protocol versions while preserving the current 2026-era path.
- Classify forwarded HTTP errors as `backend_rejected` in terminal events, including status and request ID without request bodies or credentials.

The production acceptance target is a fresh ChatGPT OAuth connection followed by an authenticated read-only `get_profile` call. No basket, order, payment, or delivery mutation is introduced.
