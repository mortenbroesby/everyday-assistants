# Nemlig Assistant 4.14.1 - Converge

## In plain language

Approved green merges now drive verified production releases and safely bounded cleanup of old Container images.

## Changes

- Routine delivery uses the exact green `main` commit; manual workflow dispatch is reserved for recovery.
- Cloudflare plaintext variables are replaced from reviewed repository config while encrypted secrets remain intact.
- Image cleanup follows read-only runtime acceptance, retains recent accepted images, and protects active, recovery, and uncertain references.
- The initial cleanup requires a reviewed dry-run plan; interrupted deletions resume only after fresh registry readback.

No basket, order, payment, or delivery mutation is introduced. This code change does not itself perform live image cleanup.
