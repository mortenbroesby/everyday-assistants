# Nemlig Assistant 6.1.1 - Unison

## In plain language

This patch makes a normal production release ask Cloudflare to replace the
active Container immediately when its image changes, so the live MCP server
does not remain on an older application image after the Worker revision moves
forward.

## Changes

- Use Cloudflare's immediate Container rollout mode for routine releases.
- Keep the existing exact-revision and read-only service acceptance gates; they
  remain the evidence that the Worker and Container application agree.

## Safety

This does not change provider access, shopping behavior, or basket mutation
authority. It narrows the mixed Worker/Container version window during a
release.
