# Nemlig Assistant 6.1.2 - Cadence

## In plain language

This patch lets the protected deployment recovery recognize the exact failed
Container rollout already recorded by the release workflow, so an explicitly
authorized restore can proceed instead of leaving production recovery stuck.

## Changes

- Recognize the direct, enabled-container recovery transcript emitted after a
  service-fixture acceptance failure.
- Recheck its exact Worker version, configuration, image, application version,
  and inactive rollout before any authorized restore request.
- Keep the older disabled-container recovery transcript guarded separately.

## Safety

Recovery remains single-use and explicit. A crash or uncertain provider
response consumes authorization; the workflow does not retry it automatically.
No shopping, provider-basket, authentication, or MCP behavior changes.
