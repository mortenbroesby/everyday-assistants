# Nemlig Assistant 4.13.8 - Profile

## In plain language

Authenticated profile discovery now works without provisioning a Nemlig login.

## Changes

- The Auth0-authenticated `get_profile` MCP path no longer requires provider credentials.
- Provider-backed tools remain protected by the existing credential and authorization checks.
- Legacy hosted owner-subject and provider-credential bindings are no longer read by the Worker runtime.

No provider operation, basket mutation, checkout, payment, ordering, delivery, or secret cleanup was performed by this change.
