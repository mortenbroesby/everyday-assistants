# Nemlig Assistant 4.7.0-alpha.71

This release coordinates basket-aware batch product discovery with Effect.
Repeated catalogue requests are coalesced within one plan, catalogue concurrency
stays capped at three, and fatal basket, authentication, timeout, or caller
cancellation now stops queued reads and waits for active reads to settle before
returning or retrying. Ordinary catalogue failures remain isolated to their
individual shopping lines.

A new `nemlig plan <input-file>` command runs the same strict planner from a
terminal with readable or JSON output, a bounded timeout, and SIGINT
cancellation. It validates the file before login or provider work and does not
create proposals or call basket mutation methods.

The implementation removes the superseded dual-coordinator scaffolding and
keeps the native worker pool only as benchmark evidence. A credential-free
localhost acceptance now exercises the real CLI handler and Node fetch across
success, basket failure, and cancellation, including concurrency, queue-stop,
request-settlement, and socket-closure assertions.
