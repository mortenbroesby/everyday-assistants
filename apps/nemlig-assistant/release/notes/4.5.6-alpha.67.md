# Nemlig Assistant 4.5.6-alpha.67

This release adds a readable, reviewed release history to the existing protected
Nemlig deployment flow.

## Changed

- Coding agents now write one versioned epic summary that CI validates and
  publishes as a GitHub prerelease after the exact revision is deployed.
- Product relevance matching reuses its normalized query words instead of
  rebuilding the same collection for each check. Characterization coverage
  confirms that Danish accents, compound names, pet-food exclusions, quantities,
  duplicate words, and prefix boundaries behave exactly as before.
- GitHub artifact transfer actions now use their current Node 24 releases.

## Release safety

- Publication requires the successful routine deployment journal for this exact
  commit, including edge and service-fixture acceptance.
- Conflicting tags or release content fail closed; matching partial publication
  can resume without redeploying.
- The npm package remains private and is not published.
