# Nemlig Assistant 4.6.0-alpha.69

The proposed-basket picker now uses a production-ready, self-contained React
interface built with OpenAI Apps SDK UI, Tailwind CSS, and the supported Vite
browser pipeline. A reusable Nemlig presentation foundation and local synthetic
showcase keep future visual interactions aligned without shipping showcase code.

The picker follows host theme, design variables, fonts, and safe-area context,
reports its size to the host, and prevents repeated alternative selections while
a message is pending. It keeps the existing reviewed-proposal and exact
alternative-choice behavior, removes the browser-time unpkg dependency and the
MVP CSS/HTML rewrite step, and still cannot apply a proposal or change a basket.
The MCP Apps feature flag remains the immediate fallback.
