# Nemlig Assistant 4.6.0-alpha.69

The proposed-basket picker now uses a self-contained React interface built with
OpenAI Apps SDK UI and Tailwind CSS. It keeps the existing reviewed-proposal and
alternative-choice behavior while removing the browser-time unpkg dependency.

The picker follows host light and dark themes, reports its size to the host, and
prevents repeated alternative selections while a message is pending. The MCP
Apps feature flag remains the immediate fallback, and the picker still cannot
apply a proposal or change a basket.
