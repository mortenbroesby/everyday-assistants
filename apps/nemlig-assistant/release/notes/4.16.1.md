# Nemlig Assistant 4.16.1 - Versioned

## In plain language

Refresh the product-review widget safely after deployment so current shopping controls are not paired with stale cached HTML.

## Changes

- Version the MCP Apps product-review resource URI whenever the self-contained viewer changes.
- Keep the service resource allow-list, MCP metadata, package smoke test, and production acceptance bound to the same versioned URI.
- Reject the retired unversioned viewer URI instead of allowing stale widget content to masquerade as current.
