# Nemlig Assistant 5.2.1 - Context

## In plain language

Product search now uses the delivery-zone context refreshed from the current
Nemlig session, rather than always querying zone 1.

## Changes

- Send the session's current delivery-zone ID with Nemlig catalogue-search
  requests, matching the session context already used for exact product lookup.
- Add a regression assertion so future search changes cannot silently revert
  to the hard-coded zone.

## Acceptance boundaries

The focused client suite and full Nemlig test suite passed with fixture-backed
session context. Live ChatGPT/Nemlig search acceptance remains pending; no real
basket was read or changed as part of this fix.
