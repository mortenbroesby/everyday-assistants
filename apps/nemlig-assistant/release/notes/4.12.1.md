# Nemlig Assistant 4.12.1 - Continuity

## In plain language

This release keeps Nemlig Assistant available during ordinary deployments and
lets ChatGPT reconnect cleanly when a deployment replaces an older connection.

## Changes

- Keeps the public assistant enabled while Cloudflare rolls out a routine update.
- Returns the standard reconnect signal when an old MCP session no longer exists.
- Preserves the stricter disabled-first procedure for the initial supervised
  cutover.
- Fails closed on an unhealthy routine candidate without rebuilding or rolling
  the Container a second time.
- Preserves authentication, quotas, the one-Container ceiling, read-only
  acceptance, and all basket approval and no-retry safeguards.
