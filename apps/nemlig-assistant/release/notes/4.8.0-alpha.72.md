# Nemlig Assistant 4.8.0-alpha.72

This release makes proposed grocery choices easier to review on mobile. Each
product now forms its own visual island. Collapsed alternatives name the
ingredient they belong to, so the relationship stays clear when the list is
expanded.

Product cards use smaller typography, keep descriptions visible, place the
compact proposed badge or selection action below the image, and expose product
description, declaration, and supplied item details through independent
disclosures. The browser contract now preserves Nemlig's bounded product-detail
fields for that presentation.

The repository showcase uses the same production picker component with
synthetic data for future demonstrations and design refinements. Product
discovery behavior remains unchanged: concurrency stays capped at three,
request-local searches remain coalesced, and fatal failure or cancellation
stops queued reads and settles active work.
