# Nemlig Assistant 4.14.0 - Showcase

## In plain language

Product searches now return richer details in one reusable viewer, with the MCP service using a modern stateless protocol.

## Changes

- Search results hydrate detailed product facts and use one shared display-only product viewer.
- The MCP server now uses the stable v2 SDK over stateless HTTP while keeping basket reviews principal-scoped across requests.
- Existing authentication, admission, and explicit basket-review safeguards remain in place.

No live provider operation, basket mutation, checkout, payment, ordering, delivery, deployment, or secret cleanup was performed.
