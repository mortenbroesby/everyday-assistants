# Nemlig Assistant 4.12.2 - Lifeline

## In plain language

This release gives ChatGPT a clear way to reconnect Nemlig Assistant when its
authorization expires instead of leaving the assistant disabled.

## Changes

- Adds a visible `Reconnect Nemlig Assistant` action.
- Prompts ChatGPT to reconnect automatically when authorization is missing or
  no longer valid.
- Marks every assistant action with its Auth0 requirement so ChatGPT can guide
  recovery consistently.
- Preserves quotas, read-only checks, and all basket approval and no-retry
  safeguards.
