# Nemlig Assistant 6.1.5 - Beacon

## In plain language

This patch makes the production workflow expose its preflight decision through
the standard GitHub Actions shell output channel. A ready release can now reach
the deployment job after recovery has released its lease.

## Changes

- Validate the read-only preflight result, then write a single explicit
  `readiness` output from the workflow shell.
- Keep the held-lease outcome as a clean, visible skip with its saved lease
  identity.

## Safety

The preflight remains credential-free and does not deploy when a recovery lease
is held. Basket, Auth0, and Nemlig-provider behavior are unchanged.
