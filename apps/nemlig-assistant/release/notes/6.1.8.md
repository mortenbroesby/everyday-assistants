# Nemlig Assistant 6.1.8 - Clementine

## In plain language

MoJo Shopper is the new human-facing name for the private family grocery app.
The stable MCP identifier, existing ChatGPT app record, MCP URL, OAuth setup,
permissions, connected account, tools, and basket safeguards remain unchanged.

## Changes

- Advertise `MoJo Shopper` in MCP and OAuth resource metadata.
- Add a compact bag-and-M icon to standard MCP server metadata.
- Package SVG and PNG logo assets for the ChatGPT listing and composer icon.
- Update visible reconnect and product-viewer wording.

## Safety

This is a presentation-only release. It does not change authentication,
authorization, provider access, local review state, or the add-only protected
Nemlig basket submission path.
