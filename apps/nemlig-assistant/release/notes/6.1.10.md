# Nemlig Assistant 6.1.10 - Tarragon

## In plain language

Choosing an alternative is now a clear tap on the product itself. Product
details are shorter, easier to scan, and keep the useful information together.

## Changes

- Make each alternative comparison row a full-width accessible selection target.
- Keep replacement behind the existing explicit **Use selected alternative**
  action; choosing a row still does not accept it into Ready.
- Show only **Varebeskrivelse**, **Varedeklaration**, and **Detaljer om varen**
  when a product is expanded, grouping supplied factual fields under the third
  section.
- Increase product images while preserving the 320px and 375px compact layout.
- Version the viewer resource as v12 so compatible hosts fetch this changed
  browser program rather than a cached earlier resource.

## Safety

This changes only local viewer presentation and local alternative selection.
It adds no provider call, product acceptance, or Nemlig basket mutation.
