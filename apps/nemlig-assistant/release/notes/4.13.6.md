# Nemlig Assistant 4.13.6 - Lighthouse

## In plain language

The hosted ChatGPT connector now advertises only the human sign-in permission,
so its OAuth flow does not offer an internal service permission.

## Changes

- Public OAuth metadata exposes only `use:nemlig-assistant`.
- Internal service-acceptance verification remains private and unchanged.
- Added coverage for service-enabled metadata.

No provider configuration, basket mutation, or production deployment was
performed by this change.
