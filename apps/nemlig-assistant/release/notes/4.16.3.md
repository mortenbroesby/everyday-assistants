# Nemlig Assistant 4.16.3 - Recovery

## In plain language

An old shopping card can recover when its temporary review disappears. Refresh
finds the current conversation review, or offers an explicit fresh start.

## Changes

- Stop retrying obsolete review references; never replay a failed basket edit.
- Restart from visible product IDs and quantities with fresh details and no restored acceptance or approval.
- Keep submitted or uncertain cards on the inspect-basket recovery path.
- Version the viewer resource so ChatGPT can load the updated recovery controls.
- Add a repeatable browser smoke host with real MCP transport and simulated state loss.
