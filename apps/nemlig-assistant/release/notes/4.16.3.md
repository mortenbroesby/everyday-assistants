# Nemlig Assistant 4.16.3 - Recovery

## In plain language

Recover cleanly when a temporary product review disappears after a service restart.

## Changes

- Show an explicit “Start a new review” action when an old review card is no longer available.
- Recreate the local review from the exact products and quantities already visible in the card.
- Document and test restart recovery without retrying stale review IDs or touching the provider basket.
