# Nemlig Assistant 6.1.0 - Pulse

## In plain language

Ask Nemlig Assistant for its profile to see the release that is answering now.
This avoids confusing a cached ChatGPT instruction banner with the current
server release.

## Changes

- Restore the read-only `get_profile` MCP tool for authenticated users.
- Return the live server's version and codename with the stable profile key.
- Remove version and codename text from MCP instructions because hosts can
  cache those instructions independently of a deployed server.
- Correct the older 4.19.0 ledger entry to `Lucid`, resolving its accidental
  duplicate of the unchanged 6.0.0 `Clarity` identity and restoring the
  release ledger's unique-name invariant.

## Acceptance boundaries

`get_profile` has no Nemlig provider login, product, Draft list, or basket
access. It proves only the release handling that fresh MCP request; it does not
retroactively update a historical ChatGPT card or prove that a cached widget
remounted.
