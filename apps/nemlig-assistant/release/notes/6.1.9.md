# Nemlig Assistant 6.1.9 - Saffron

## In plain language

MoJo Shopper now uses a warm orange grocery-basket icon that remains clear in
both the compact plugin picker and larger plugin presentation.

## Changes

- Replace the earlier bag-and-letter icon with an orange grocery basket,
  cream basket body, and dark-green produce details.
- Keep one 1024px square SVG master and export matching 1024px listing and
  256px composer PNG assets.

## Safety

This is a presentation-only release. It does not change the existing ChatGPT
app record, MCP URL, OAuth configuration, permissions, tools, or any Nemlig
provider or basket behavior.
