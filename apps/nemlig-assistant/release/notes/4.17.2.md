# Nemlig Assistant 4.17.2 - Service inventory evidence

## In plain language

The release guard still stops a rollout when the machine-only tool list differs from the expected safe fixture. It now records whether a known fixture tool is missing or extra entries appeared, without exposing tool names, responses, or credentials.

## Changes

- Encode missing expected service tools as a bounded positional mask and unexpected entries as a bounded count in the existing failure boundary.
- Cover a missing visual-basket action and an unexpected entry in focused tests.
- Keep acceptance, rollback, and provider/basket safety unchanged.

This release is diagnostic. It does not claim the newer candidate passed production or ChatGPT acceptance.
