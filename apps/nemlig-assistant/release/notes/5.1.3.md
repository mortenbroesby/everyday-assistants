# Nemlig Assistant 5.1.3 - Signpost

## In plain language

Make it clearer which tool finds groceries, reopens a local review, or changes
the real Nemlig basket—without changing the shopping workflow.

## Changes

- Group the existing MCP routing instructions into catalogue, actual basket,
  local review, protected submission and recovery sections.
- Distinguish search, exact lookup and explicit review start from reopening the
  current conversation's draft. Preserve local In Review/Ready semantics.
- Missing/stale review errors direct a current-state read without old references
  or replay. Empty alternatives and unavailable products remain unresolved.
- Reconcile the local basket skill with retired planner/automatic authority and
  exact approval through the existing protected prepare/apply paths.
- Extend existing independent catalogue and synthetic recovery tests; no new
  dependency, schema, viewer identity, business-state model or provider write path.

## Acceptance boundaries

Local MCP and browser verification is not native ChatGPT acceptance. No deployment,
app Refresh, credential/configuration change or real basket write is part of this
repository fix. #67/#96/#137 retain their independent live acceptance gates.
