# Nemlig Assistant 6.3.0 - Marigold

## In plain language

When you submit a Local basket, Nemlig Assistant now prepares the exact items
in a temporary Nemlig shopping list and checks that list before adding it to
your real Nemlig basket. The actual basket remains add-only and is checked
afterwards.

## Changed

- Added a guarded provider shopping-list preparation path for Local-basket
  submission.
- Reads back every temporary list before preparing an exact transfer, then
  uses Nemlig's native one-list-to-basket operation.
- Recorded the private provider endpoints in the audited API manifest.

## Safety

- Local-basket storage remains the source of truth for this proof release;
  provider-list workspace migration is a separate follow-up after live smoke
  evidence.
- The existing authorization, fresh product checks, principal binding,
  single-use submission fence, basket readback, and no-retry-on-uncertainty
  safeguards remain in force.
