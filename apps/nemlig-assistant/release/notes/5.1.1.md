# Nemlig Assistant 5.1.1 - Threshold

## In plain language

Fix owner sign-in failing before the login screen in the deployed Worker.

## Changes

- Use the Worker's supported manual redirect mode for bounded issuer requests,
  and reject every redirect response before the OAuth client can continue.
- Preserve pinned destinations, PKCE, exact owner/token checks, single-use
  session authority and no automatic exchange retry. No credential replacement
  or basket mutation occurs just from opening or signing in to the page.
- Add regressions for the Worker redirect-mode boundary and discovery/exchange
  redirects. No new dependencies, configuration, viewer resource or workflow.

## Live acceptance

The 5.1.0 onboarding-only smoke failed before owner authentication. Both MCP
and onboarding remain disabled pending the reviewed fix and live owner/provider
acceptance. Local Worker-runtime smoke does not prove production sign-in,
stored Nemlig credential readiness or native ChatGPT acceptance.
