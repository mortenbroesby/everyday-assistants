# Nemlig Assistant 6.1.3 - Harbor

## In plain language

This patch makes a normal release stop clearly before deployment when an older
production recovery is still unresolved. It no longer starts a second failed
release or leaves misleading finalization work behind.

## Changes

- Check the shared production lease after source, CI, and environment proof.
- Report a held lease as `blocked_by_existing_lease` with an actionable
  workflow summary.
- Skip the protected deploy, finalization, and retention jobs until explicit
  recovery reconciliation resolves the held lease.

## Safety

Atomic lease acquisition remains the final race check. This does not release a
lease, retry a provider operation, change Cloudflare, or alter shopping,
authentication, or MCP behavior.
