# Nemlig Assistant 4.9.0 - Callsign

## In plain language

This release gives each deployed version a unique nickname, so it is easier to recognize and discuss which version is running.

## Changes

- Adds a unique, reviewed codename to each deployed Nemlig Assistant release.
- Reports the deployed version and codename to ChatGPT through existing MCP instructions.
- Keeps version-only tags and publishes the codename only after exact-candidate deployment succeeds.
