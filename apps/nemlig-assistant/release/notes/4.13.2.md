# Nemlig Assistant 4.13.2 - Handshake

## In plain language

This patch makes the ChatGPT OAuth connection fail safely and more clearly when
the authorization server is misconfigured, while documenting the deployment
and reconnect procedure for the existing Nemlig Assistant app.

## Changes

- Rejects Auth0 discovery documents whose authorization, token, or JWKS
  endpoints are not HTTPS.
- Rejects Auth0 discovery documents that do not advertise PKCE S256.
- Adds the stable Nemlig Assistant resource name to protected-resource
  metadata.
- Records the Relay deployment incident, official Apps SDK comparison, and
  safe release/reconnect procedure without storing credentials or private data.
