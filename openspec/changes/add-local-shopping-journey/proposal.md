## Why

Agents need a repeatable manual smoke test that distinguishes a provider-adapter regression, a changed MCP contract and a broken review card.

## What Changes

- Exercise the three boundaries independently or in one deterministic command.
- Offer a bounded native conversation that hands its actual MCP result to the built widget.
- Exercise the same backend architecture with local Wrangler and Docker and report timings for two equivalent discoveries.
- Keep the operator live-read profile separate.

## Capabilities

### New Capabilities

- `nemlig-manual-smoke` describes the manual test profiles.

## Impact

The manual commands use existing fixtures, the protocol SDK, Chrome, and optional local container tooling. The default suite runs without cloud credentials.
