# Release glossary

Nemlig Assistant release notes lead with a plain-language summary. Use this
lookup when a later section contains an unfamiliar alias, acronym, or technical
term.

| Term | Plain-language alias | Meaning |
| --- | --- | --- |
| CI | Automated checks | Tests and safety checks run by GitHub before code can be released. |
| Codename | Release nickname | A unique memorable word chosen for one deployed version. |
| Deploy | Put live | Make a verified version available in the hosted service. |
| MCP | ChatGPT connection | The protocol used by ChatGPT to connect to Nemlig Assistant. |
| Prerelease | Release record | The GitHub page that records what was deployed without publishing the npm package. |
| SemVer | Version number | The `major.minor.patch` numbering format, such as `4.9.0`. |
| SHA | Exact code revision | The unique Git identifier used to prove exactly which code was checked and deployed. |

Add a row when a release note needs a technical term that a non-technical
reader may not recognize. Prefer plain words in the note when no lookup is
needed.
